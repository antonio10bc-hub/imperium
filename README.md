# Imperium

Juego de estrategia en tiempo real con estética voxel, en un único archivo HTML (Three.js por CDN).

Para jugar, abre `index.html` en el navegador.

- Mapa único: dos llanuras separadas por un río que solo se cruza por los vados.
- Barra inferior: minimapa, panel de selección (cuartel, altar, pueblos, unidades) y herramientas.
- El héroe aparece como retrato a la izquierda con el número de tropas asignadas. Su escolta (hasta 12) forma un bloque delante de él: espadas al frente, arcos detrás y jinetes en los flancos.
